NutriTrack

NutriTrack est une application Java développée pour suivre les apports nutritionnels des utilisateurs. Elle permet d'enregistrer les repas, calculer les calories et visualiser les données via une interface graphique intuitive. Ce projet a été réalisé en équipe dans le cadre d'un projet universitaire à l'École des Sciences de l'Information (ESI), Rabat.

Fonctionnalités





Enregistrement des repas avec détails (nom, calories, nutriments)



Calcul automatique des apports caloriques quotidiens



Interface graphique conviviale (JavaFX ou Swing)



Visualisation des statistiques nutritionnelles

Technologies Utilisées





Langage : Java



Interface graphique : JavaFX



Environnement : Eclipse



Gestion de projet : Méthodologies agiles

Prérequis





Java Development Kit (JDK) 23

Installation





Téléchargez le dépôt depuis GitHub.



Ouvrez le projet dans votre IDE (IntelliJ, Eclipse).



Configurez les dépendances (ex. : ajoutez JavaFX au classpath).



Exécutez la classe principale : Main.java.

Utilisation





Lancez l'application.



Ajoutez un repas via l'interface (ex. : "Petit-déjeuner : 500 kcal").



Consultez les statistiques dans la section "Tableau de bord".

Structure du Projet

ressources/ : Images, fichiers de configuration



lib/ : Bibliothèques externes
